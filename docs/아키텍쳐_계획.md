# Aroon MVC 아키텍쳐 계획

## 1. 설계 원칙

| 원칙 | 설명 |
|------|------|
| 계층형 MVC | Controller → Service → Mapper 단방향 의존 |
| 관심사 분리 | 각 계층은 자기 역할만 수행 |
| 단일 책임 | 하나의 클래스는 하나의 책임만 담당 |
| DTO 분리 | Entity를 직접 노출하지 않고 DTO로 변환 |
| 통일 응답 | 모든 API는 ApiResponse로 래핑하여 응답 |

## 4. 계층별 역할과 규칙

### 4.1 Controller 계층

```
역할: HTTP 요청 수신 → 입력 검증 → Service 호출 → 응답 반환
```

| 항목 | 규칙 |
|------|------|
| 어노테이션 | `@RestController`, `@RequestMapping("/api/...")` |
| 입력 검증 | `@Valid` + Request DTO의 Bean Validation |
| 응답 형식 | 항상 `ApiResponse<T>`로 래핑 |
| 비즈니스 로직 | 절대 포함하지 않음 (Service에 위임) |
| 파라미터 변환 | Request DTO → Entity 변환 후 Service 호출 |
| 네이밍 | `{도메인}Controller.java` |

```java
// 예시: UserController.java
@RestController
@RequestMapping("/api/users")
@RequiredArgsConstructor
public class UserController {

    private final UserService userService;

    @GetMapping
    public ApiResponse<List<UserResponse>> getUsers() {
        return ApiResponse.success(userService.getAllUsers());
    }

    @GetMapping("/{userSeq}")
    public ApiResponse<UserResponse> getUser(@PathVariable Long userSeq) {
        return ApiResponse.success(userService.getUserBySeq(userSeq));
    }

    @PostMapping
    public ApiResponse<UserResponse> createUser(@Valid @RequestBody UserCreateRequest request) {
        return ApiResponse.success(userService.createUser(request));
    }

    @PutMapping("/{userSeq}")
    public ApiResponse<UserResponse> updateUser(@PathVariable Long userSeq,
                                                 @Valid @RequestBody UserUpdateRequest request) {
        return ApiResponse.success(userService.updateUser(userSeq, request));
    }

    @DeleteMapping("/{userSeq}")
    public ApiResponse<Void> deleteUser(@PathVariable Long userSeq) {
        userService.deleteUser(userSeq);
        return ApiResponse.success(null);
    }
}
```

### 4.2 Service 계층

```
역할: 비즈니스 로직 처리, 트랜잭션 관리, 데이터 변환
```

| 항목 | 규칙 |
|------|------|
| 구조 | Interface + Impl 분리 |
| 어노테이션 | `@Service`, `@RequiredArgsConstructor` |
| 트랜잭션 | `@Transactional` (쓰기 작업) / `@Transactional(readOnly = true)` (읽기 작업) |
| 의존성 | Mapper만 주입 (다른 Service 주입 가능하나 순환 참조 주의) |
| 반환값 | Response DTO 반환 (Entity를 직접 반환하지 않음) |
| 네이밍 | `{도메인}Service.java` / `{도메인}ServiceImpl.java` |

```java
// 예시: UserService.java (인터페이스)
public interface UserService {
    UserResponse createUser(UserCreateRequest request);
    UserResponse getUserBySeq(Long userSeq);
    List<UserResponse> getAllUsers();
    UserResponse updateUser(Long userSeq, UserUpdateRequest request);
    void deleteUser(Long userSeq);
}
```

```java
// 예시: UserServiceImpl.java (구현)
@Service
@RequiredArgsConstructor
public class UserServiceImpl implements UserService {

    private final UserMapper userMapper;

    @Override
    @Transactional
    public UserResponse createUser(UserCreateRequest request) {
        User user = User.builder()
                .username(request.getUsername())
                .email(request.getEmail())
                .password(passwordEncoder.encode(request.getPassword()))
                .nickname(request.getNickname())
                .status(1)
                .build();
        userMapper.insert(user);
        return toResponse(user);
    }

    @Override
    @Transactional(readOnly = true)
    public UserResponse getUserBySeq(Long userSeq) {
        User user = userMapper.selectById(userSeq);
        if (user == null) {
            throw new BusinessException(ErrorCode.USER_NOT_FOUND);
        }
        return toResponse(user);
    }

    private UserResponse toResponse(User user) {
        return UserResponse.builder()
                .userSeq(user.getUserSeq())
                .username(user.getUsername())
                .email(user.getEmail())
                .nickname(user.getNickname())
                .status(user.getStatus())
                .createdAt(user.getCreatedAt())
                .build();
    }
}
```

### 4.3 Mapper 계층

```
역할: DB 접근, SQL 실행 (MyBatis-Plus BaseMapper 활용)
```

| 항목 | 규칙 |
|------|------|
| 기본 | `BaseMapper<Entity>` 상속 → CRUD 자동 제공 |
| 어노테이션 | `@Mapper` |
| 단순 쿼리 | BaseMapper 내장 메서드 활용 |
| 복잡 쿼리 | XML 매퍼 파일 또는 `@Select`/`@Update` 어노테이션 |
| XML 위치 | `src/main/resources/mapper/{도메인}Mapper.xml` |
| 네이밍 | `{도메인}Mapper.java` |

```java
// 예시: UserMapper.java
@Mapper
public interface UserMapper extends BaseMapper<User> {

    // BaseMapper가 제공하는 기본 메서드:
    // - insert(entity)
    // - selectById(id)
    // - selectList(wrapper)
    // - updateById(entity)
    // - deleteById(id)
    // - selectPage(page, wrapper)

    // 복잡한 쿼리는 XML 매퍼 또는 어노테이션으로 추가 정의
    // 예: 사용자 + 역할 조인 조회
    List<User> selectUserWithRoles(@Param("userSeq") Long userSeq);
}
```

**MyBatis-Plus BaseMapper 기본 제공 메서드:**

| 메서드 | 설명 |
|--------|------|
| `insert(T entity)` | 엔티티 삽입 |
| `deleteById(Serializable id)` | PK로 삭제 |
| `updateById(T entity)` | PK로 수정 (null 필드 제외) |
| `selectById(Serializable id)` | PK로 조회 |
| `selectList(Wrapper)` | 조건 목록 조회 |
| `selectPage(Page, Wrapper)` | 페이징 조회 |
| `selectCount(Wrapper)` | 건수 조회 |
| `selectBatchIds(Collection)` | ID 배치 조회 |
| `deleteBatchIds(Collection)` | ID 배치 삭제 |

### 4.4 Entity 계층

```
역할: DB 테이블과 1:1 매핑되는 도메인 객체
```

| 항목 | 규칙 |
|------|------|
| 어노테이션 | `@TableName`, `@TableId`, `@TableField` (MyBatis-Plus) |
| Lombok | `@Data`, `@Builder`, `@NoArgsConstructor`, `@AllArgsConstructor` |
| PK 전략 | `@TableId(type = IdType.AUTO)` (Auto Increment) |
| 필드 매핑 | underscore_case → camelCase 자동 변환 (설정 완료) |
| 네이밍 | `{도메인}.java` |

```java
// 예시: User.java
@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
@TableName("user")
public class User {

    @TableId(value = "user_seq", type = IdType.AUTO)
    private Long userSeq;

    private String username;
    private String password;
    private String email;
    private String nickname;
    private Integer status;
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
}
```

### 4.5 DTO 계층

```
역할: 계층 간 데이터 전달, 입력 검증, 민감 정보 필터링
```

| 구분 | 역할 | 위치 |
|------|------|------|
| Request DTO | 클라이언트 입력 + 유효성 검증 | `dto/request/` |
| Response DTO | 클라이언트 응답 (민감 정보 제외) | `dto/response/` |

```java
// 예시: UserCreateRequest.java
@Data
public class UserCreateRequest {

    @NotBlank(message = "사용자명은 필수입니다")
    @Size(min = 3, max = 50)
    private String username;

    @NotBlank(message = "비밀번호는 필수입니다")
    @Size(min = 8, max = 100)
    private String password;

    @Email(message = "이메일 형식이 올바르지 않습니다")
    private String email;

    private String nickname;
}
```

```java
// 예시: UserResponse.java (password 제외)
@Data
@Builder
public class UserResponse {
    private Long userSeq;
    private String username;
    private String email;
    private String nickname;
    private Integer status;
    private LocalDateTime createdAt;
}
```

## 5. 공통 모듈 상세

### 5.1 ApiResponse (통일 응답 래퍼)

```java
@Data
@Builder
public class ApiResponse<T> {
    private int code;
    private String message;
    private T data;
    private LocalDateTime timestamp;

    public static <T> ApiResponse<T> success(T data) {
        return ApiResponse.<T>builder()
                .code(200)
                .message("Success")
                .data(data)
                .timestamp(LocalDateTime.now())
                .build();
    }

    public static <T> ApiResponse<T> error(int code, String message) {
        return ApiResponse.<T>builder()
                .code(code)
                .message(message)
                .data(null)
                .timestamp(LocalDateTime.now())
                .build();
    }
}
```

### 5.3 GlobalExceptionHandler (전역 예외 처리)

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ApiResponse<Void> handleBusinessException(BusinessException e) {
        return ApiResponse.error(e.getErrorCode().getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ApiResponse<Void> handleValidationException(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
                .map(FieldError::getDefaultMessage)
                .findFirst()
                .orElse("유효성 검증 실패");
        return ApiResponse.error(400, message);
    }

    @ExceptionHandler(Exception.class)
    public ApiResponse<Void> handleException(Exception e) {
        return ApiResponse.error(500, "서버 내부 오류입니다");
    }
}
```

### 5.4 MybatisPlusConfig (MyBatis-Plus 설정)

```java
@Configuration
public class MybatisPlusConfig {

    // 페이징 플러그인
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }

    // 자동 채움 핸들러 (created_at, updated_at 자동 설정)
    @Bean
    public MetaObjectHandler metaObjectHandler() {
        return new MetaObjectHandler() {
            @Override
            public void insertFill(MetaObject metaObject) {
                this.strictInsertFill(metaObject, "createdAt", LocalDateTime::now, LocalDateTime.class);
                this.strictInsertFill(metaObject, "updatedAt", LocalDateTime::now, LocalDateTime.class);
            }
            @Override
            public void updateFill(MetaObject metaObject) {
                this.strictUpdateFill(metaObject, "updatedAt", LocalDateTime::now, LocalDateTime.class);
            }
        };
    }
}
```

## 7. 모듈별 구성 요소 매트릭스

| 모듈 | Controller | Service | ServiceImpl | Mapper | Entity | Request DTO | Response DTO |
|------|:----------:|:-------:|:-----------:|:------:|:------:|:-----------:|:------------:|
| Auth | AuthController | AuthService | AuthServiceImpl | - | - | LoginRequest | LoginResponse |
| User | UserController | UserService | UserServiceImpl | UserMapper | User | UserCreate/UpdateRequest | UserResponse |
| Role | RoleController | RoleService | RoleServiceImpl | RoleMapper | Role | RoleCreate/UpdateRequest | RoleResponse |

## 8. XML 매퍼 파일 구조

복잡한 조인 쿼리가 필요한 경우 XML 매퍼를 사용합니다.

```
src/main/resources/
└── mapper/
    ├── UserMapper.xml              # 사용자 + 역할 조인 조회
    ├── RoleMapper.xml              # 역할 + 권한/메뉴 조인 조회
    ├── PermissionMapper.xml        # (필요 시)
    └── MenuMapper.xml              # 메뉴 트리 조회
```

```xml
<!-- 예시: UserMapper.xml -->
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.aroon.business.mapper.core.UserMapper">

    <select id="selectUserWithRoles" resultMap="userWithRolesMap">
        SELECT u.user_seq, u.username, u.email, u.nickname, u.status,
        r.role_seq, r.role_code, r.role_name
        FROM user u
        LEFT JOIN user_role ur ON u.user_seq = ur.user_seq
        LEFT JOIN role r ON ur.role_seq = r.role_seq
        WHERE u.user_seq = #{userSeq}
    </select>

</mapper>
```
